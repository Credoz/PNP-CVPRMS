IPO: Process 2.0 — Real-Time Screening
INPUT
• Plate Number
• Driver Name
• License Number
• D2: Watchlist
PROCESS
1. Normalize identifiers (uppercase, strip '-').
2. Match against HPG stolen plates & warrant list.
3. Evaluate tri-state outcome (clear / warning / alarm).
OUTPUT
• Status: 'clear' | 'warning' | 'alarm'
• UI Alert Badge
• Screening flags
IPO: Process 3.0 — Citation Ingestion
INPUT
• Citation Payload
• Alt ID / Tow Slip
• Raw photo file
• D3: Fee Schedule
PROCESS
1. Execute 11 defensive validation rules.
2. Downscale photo on canvas (max 1200px).
3. Verify statutory / discretionary fine sum.
4. Insert into D1.
OUTPUT
• Record in D1
• Ticket Number
• HTTP 201 Created
• Thermal Slip
IPO: Process 5.0 — Treasury Settlement
INPUT
• Violation Record ID
• New payment status
• Treasury User action
PROCESS
1. Validate ID is positive integer.
2. Check status against allowed whitelist.
3. Execute parameterized UPDATE query.
4. Sync local state.
OUTPUT
• Updated payment_status in D1
• HTTP 200 Success
• Reactive KPI reload
