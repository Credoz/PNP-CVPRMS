1. Violations Physical Table Schema (SQLite 3.x)
# Column Name Data Type Constraints Default Value Description & Operational Business Rules
1 id INTEGER PRIMARY KEY AUTOINCREMENT Auto-generated Unique surrogate primary key automatically incremented by the SQLite storage engine.
2 driver_name TEXT NOT NULL None Full legal name of apprehended motorist as stated on license or alternative government ID.
3 license_number TEXT NOT NULL None LTO Driver's License number (e.g. N01-12-345678). Explicitly set to 'N/A - Unlicensed' if unlicensed.
4 id_type TEXT NULLABLE NULL Government ID type (PhilSys, Passport, UMID, PRC, Postal ID, Voter's ID) required if driver is unlicensed.
5 id_number TEXT NULLABLE NULL Identification number on alternative government document presented by unlicensed motorists.
6 plate_number TEXT NOT NULL None Vehicle license plate or temporary MV file number (e.g. ABC-1234, 1234-567890).
7 vehicle_type TEXT NULLABLE 'Private/Sedan (UV)' Classification: Motorcycle (MC), Tricycle (TC), Private/Sedan (UV), SUV/AUV, Commercial/Truck.
8 vehicle_disposition TEXT NULLABLE 'Released with Citation' Disposition state: 'Released with Citation', 'Impounded at Base / Station', 'Turned over to LTO / HPG'.
9 impound_receipt_no TEXT CONDITIONAL NULL Mandatory serial number of physical towing slip / impound receipt when vehicle_disposition is Impounded.
10 shift_info TEXT NULLABLE NULL Operational checkpoint duty shift: 'Shift 1 (06:00 - 14:00)', 'Shift 2 (14:00 - 22:00)', 'Shift 3 (22:00 - 06:00)'.
11 checkpoint_post TEXT NULLABLE NULL Designated checkpoint post name / location (e.g. 'Boundary Post Alpha', 'National Highway Bravo').
12 payment_status TEXT CHECK ENUM 'Unsettled / Unpaid' Treasury settlement status: 'Unsettled / Unpaid', 'Settled / Paid at Treasury', or 'Voided / Contested'.
13 evidence_image TEXT NULLABLE NULL Lossy Base64 Data URL (data:image/jpeg;base64,...) of downscaled confiscated document or plate photo.
14 fine_override INTEGER BOOLEAN FLAG 0 Flag: 0 = Statutory schedule enforced; 1 = Officer authorized manual fine override entered.
15 violation_type TEXT NOT NULL None Comma-delimited string of itemized statutory traffic offenses cited during checkpoint stop.
16 fine_amount REAL NOT NULL > 0 None Total assessed monetary penalty in Philippine Pesos (PHP). Must strictly equal schedule sum unless overridden.
17 officer_id TEXT NOT NULL None Unique badge ID of apprehending PNP checkpoint officer (e.g. 'PNP-OFFICER-4491').
18 date_recorded TEXT NOT NULL None ISO-formatted timestamp of citation creation in local Philippine Standard Time (YYYY-MM-DD HH:mm:ss).
19 ticket_number TEXT UNIQUE SEED None Unique citation ticket identifier format: PNP-<timestamp_suffix>-<6_char_random> (e.g. PNP-24891102-K8M4Q2).
20 screening_status TEXT CHECK ENUM 'clear' Automated triage result against watchlist: 'clear' (No flags), 'warning' (Suspended), or 'alarm' (HPG Wanted).
